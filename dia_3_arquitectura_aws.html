3.3 Route 53 (DNS y Dominio)

Permite registrar dominios y dirigir el tráfico. **Registros A de tipo Alias:** Apuntan directamente a recursos de AWS como Application Load Balancers (ALB) de forma dinámica sin usar direcciones IP fijas.

3.4 Balanceo de Carga (ALB)

Distribuye el tráfico entre múltiples instancias EC2 en distintas Zonas de Disponibilidad (us-east-1a, us-east-1b). **Target Groups:** Agrupan las instancias y ejecutan **Health Checks** para evitar enviar tráfico a servidores caídos.

3.1 Redes VPC y Subredes

Para mayor seguridad, los servidores web EC2 se ubican en **Subredes Privadas** (sin IP pública directa). El ALB se ubica en **Subredes Públicas** recibiendo peticiones de la red y redirigiéndolas hacia las EC2 privadas.

3.2 Almacenamiento (EBS y S3)

**Amazon EBS:** Disco de bloques conectado localmente a una EC2 (`/mnt/datos-ebs`) para rápido acceso en lecturas. **Amazon S3:** Bucket de objetos para respaldos globales y sincronización estática mediante IAM Roles.
